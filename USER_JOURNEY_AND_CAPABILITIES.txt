1. SYSTEM OVERVIEW — PROBLEM YEH SYSTEM KAISE SOLVE KARTA HAI?
--------------------------------------------------------------------------------
Traditional cold email tools (jaise Lemlist, Apollo, Instantly) static sequences run
karty hain. Agar koi template fail ho rha ho ya bounce zyada aa rhy hon, to insaan
ko dashboard check kr k manually change krna parta hai tab tak domain burn ho chuki hoti hai.

Yeh agent graph8 ke intent data + real-time webhooks + Groq LLM ke through:
1. Intent signals discover karta hai (kaunsi companies active solutions research kr rhi hain).
2. Two-Tier Prospect Management:
   - "Total Prospects to Fetch": Ek hi bar pora cohort (e.g. 23 ya 100) fetch kar k 
     database me store karta hai taa k Prospects tab me saray leads foran nazar aayein.
   - "Daily Send Pacing Limit": Daily batch size (e.g. 7 ya 25/day) enforce karta hai 
     taa k email deliverability safe rahy.
3. Exact Proportional Variant Split:
   - Modulo hash ki jagah exact proportional balancer use hota hai. Agar 7 daily limit hai,
     to exactly 4 Variant A ko aur 3 Variant B ko jaati hain. Aglay din 3 Variant A aur 4 Variant B!
4. 15-Day Reinforcement Tournament & Variant C Evolution:
   - Days 1–15 (Phase 1: Exploration): 50% Variant A / 50% Variant B.
   - Day 15 Milestone: Bayesian Laplace score evaluate hota hai. Winning Champion ko 80%
     traffic par scale kiya jata hai, underperformer ko retire kiya jata hai, aur LLM
     winner ke DNA se Variant C (Challenger) breed karta hai aglay 15 din k tournament k liye!
5. Human-in-the-Loop (HITL) Safety: First send, copy changes, aur prospect reply drafts
   Approvals queue me 1-click human clearance k baghair launch nahi hoty.

--------------------------------------------------------------------------------
2. COMPLETE END-TO-END USER JOURNEY (QADAM BA QADAM)
--------------------------------------------------------------------------------

STEP 1: SETTINGS MEIN CREDENTIALS CONNECT KARNA
- Dashboard -> "Settings" (/settings) tab open karein:
  * Graph8 API Key enter karein (with checked permissions).
  * Mailbox Settings: Apna custom SMTP (host, port, user, app password) aur IMAP credentials set karein.
- System verify karega aur real-time outbound/inbound connectivity activate ho jayegi.

STEP 2: REFERENCE EMAILS (AI KA WINNING KNOWLEDGE BASE)
- Dashboard -> "Reference Emails" (/reference-emails) tab mein proven winning copies loaded hain.
- User apni past ki top-performing cold emails add kr sakta hai.
- Groq LLM inhi emails k style, hook, aur low-friction ask ko learn kr k naye variants likhta hai.

STEP 3: CAMPAIGN CREATE KARNA (TOTAL COHORT VS DAILY PACING)
- Dashboard -> "Campaigns" tab me "New Campaign" click karein:
  * Campaign Name, Target Industry, Persona Titles, aur Intent Keywords define karein.
  * Input 1: "Total Prospects to Fetch & Enrich" (e.g. 23 ya 100) -> Ye saary prospects DB me store honge.
  * Input 2: "Daily Campaign Send Pacing Limit" (e.g. 7 ya 25/day) -> Ye daily batch size hai.
- "Launch Campaign" dabayein:
  * LangGraph signal_node aur enrichment_node execute hoty hain.
  * variant_generator_node Variant A aur Variant B likhta hai.
  * IMPORTANT: Agent yahan foran ruk jata hai (HITL Gate 1)! Koi b email human clearance se pehle send nahi hoti!

STEP 4: PROSPECTS TAB MEIN CAMPAIGN LINKAGE & PAGINATION
- Dashboard -> "Prospects" (/prospects) tab me:
  * Tamam 23 prospects foran enriched data (verified email, LinkedIn, tech stack) k sath appear hoty hain.
  * Har prospect row par uski Campaign Name & ID ka distinct badge nazar aata hai.
  * Dropdown se specific campaign k prospects filter kar sakty hain.
  * Pagination toolbar (10, 15, 25, 50 rows per page) se large cohorts smoothly browse karein.

STEP 5: HITL APPROVALS QUEUE (FULL BODY PREVIEW & EDITING)
- Dashboard -> "Approvals" (/approvals) tab me notification hoti hai.
- "Review & Approve" click karein:
  * Side-by-side view me Variant A (Pain-point angle) aur Variant B (ROI metric angle) dono k
    Full Subjects aur Full Email Bodies clearly nazar aaty hain.
  * Live character counts aur merge tags ({name}, {company}, {title}) available hain.
  * Aap subject ya body me live editing kar sakty hain.
- "Approve & Activate" click karein:
  * Aapki edited copy SQLite database me save hoti hai.
  * Pehla daily batch (e.g. 7 prospects) active sequence me dispatch hota hai!

STEP 6: EXACT PROPORTIONAL BALANCING & DAILY SCHEDULER
- 7 prospects me se:
  * Exactly 4 Variant A ko enroll hoty hain.
  * Exactly 3 Variant B ko enroll hoty hain.
  * Remaining 16 prospects status 'new' me rehty hain.
- Next day:
  * Automated background scheduler agla 7 ka batch uthata hai (3 Variant A aur 4 Variant B).
  * 14 sends k bad exact 7 aur 7 ka balance ban jata hai!
- Active campaign card par "Push Next Daily Batch Now" button se aap kabhi b manual batch trigger kr sakty hain.

STEP 7: REAL-TIME WEBHOOK TELEMETRY & SENTIMENT ANALYSIS
- Jab prospects email open ya reply krty hain:
  * Webhook event (/api/webhooks/graph8) ingest hota hai.
  * Variant metrics (opens, replies, positive replies, bounces) update hoty hain.
  * Inbound replies ko Groq LLM classify karta hai:
    - Positive: Meeting ya demo requested.
    - Neutral: Information query.
    - Objection: Price/timing concern.
  * Server-Sent Events (SSE) k through dashboard real-time live update hota hai.

STEP 8: DEDICATED VARIANT ANALYTICS DASHBOARD
- Sidebar se "Variant Analytics" (/analytics) tab open karein:
  * Top KPI cards: Outbound Sent, Deliverability %, Open Rate %, Reply Rate %, Positive %, Bounces.
  * A/B Head-to-Head Comparison Cards: Variant A vs Variant B ki comparative progress bars, 
    Bayesian confidence score, aur expandable email copy preview.
  * Intent Velocity Distribution: Tier 1 Hot (90+), Tier 2 Warm, Tier 3 Mild breakdown.

STEP 9: 15-DAY REINFORCEMENT TOURNAMENT & VARIANT C EVOLUTION
- Days 1–15: 50/50 Exploration Tournament.
- Day 15 Milestone:
  * Evaluator Bayesian formula se score calculate karta hai:
    Score = ((0.15*Open + 0.35*Reply + 0.50*Pos) * N + 3*0.05) / (N + 3)
  * Highest-performing variant ko "Champion" bana kar 80% traffic par scale karta hai.
  * Underperformer ko 0% (retire) karta hai.
  * LLM Champion k winning hooks se Variant C (Challenger) breed karta hai (20% traffic).
  * Days 16–30: Champion vs Variant C tournament start ho jata hai!
- Demo Feature: Analytics page par "Evaluate 15-Day Milestone Now" button click kar k
  aap kisi b waqt live simulation daikh sakty hain!

STEP 10: UNIFIED INBOX, AI CONTEXTUAL REPLIES, & VOICE ESCALATION
- Dashboard -> "Inbox" (/inbox) me incoming replies show hoti hain.
- LLM automatically context-aware reply draft generate karta hai.
- User 1-click me draft review kar k send karta hai.
- Score >= 90 waly accounts par Voice Escalation gate trigger hota hai phone calling k liye.
